# Квиз в узких кругах

Веб-квиз для игры с друзьями по видеозвонку: ведущий открывает страницу, шерит экран и ведёт игру.

**Играть онлайн:** https://n-alexeyev.github.io/kviz-v-uzkih-krugah/

Локально: откройте `index.html` в браузере (двойным кликом), разверните на весь экран (F).

**Управление:** → / пробел / Enter — дальше (или «показать ответ»), ← — назад, F — полный экран, P — пауза таймера, M — звук.
Клик по картинке увеличивает её. Незаконченная игра сохраняется в браузере — её можно продолжить с главного экрана.

## Как добавить новый квиз

1. Создайте папку `quizzes/4/` и положите туда картинки (например, в `quizzes/4/img/`).
2. Скопируйте `quizzes/3/quiz.js` в `quizzes/4/quiz.js`, поменяйте `id: "4"`, название и вопросы.
3. Допишите строку `{ id: "4", title: "Квиз №4" }` в `quizzes/index.js`.

Поля вопроса: `text`, `images` (путь, `{ src, caption }` или `{ emoji }`), `options` (варианты A–D), `hints` (подсказки плиткой), `answer`, `answerImages` (картинки, которые заменят исходные после показа ответа), `comment`, `todo: true` (вопрос неполный — подсвечивается на старте).

Турнирная таблица показывается после каждого 3-го тура, в конце — победитель.

В репозитории опубликован только квиз по Хеллоуину; остальные квизы и папка `raw/` хранятся локально (см. `.gitignore`).
